Financial Machine Learning

Sixteen units, from what machine learning is to the parts that only matter in finance — bars instead of the calendar, the triple barrier instead of "will it go up tomorrow", purged cross-validation instead of a naive backtest. Every unit is a lecture and three hands-on problems, with the data included.

Every problem ships its data

There is no download step and no vendor account. Each unit's data/ directory holds the small CSVs its three problems use, chosen so the hand-calculation in the problem set and the code you write afterwards agree exactly. Clone the repository, or open any file straight in the browser — GitHub renders CSV as a table.

git clone https://github.com/keerhee/financial-machine-learning.git

Anomaly detection runs as its own thread across the algorithms — LOF in unit 5, OCSVM in unit 6, Isolation Forest in unit 7, the autoencoder in unit 8 — because in production no single detector is enough. The same three applications (product recommendation, fraud detection, an AI chatbot) are revisited at every new level of machinery.

Week 8 is the midterm and week 16 the final, so the sixteen units are taught in fourteen weeks. Week 5 takes the three simple classifiers together with the support vector machine; week 14 takes causality and fairness together with the frontier. The examination papers fix where the line falls — units 1–8 before, units 9–16 after. See the curriculum map.
